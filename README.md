## 🌟 Overview

An Awwwards-inspired immersive 3D portfolio showcasing production backend engineering, machine learning pipelines, and cloud system deployments. Built with a modern **Black & Gold** aesthetic featuring real-time WebGL rendering, smooth momentum scrolling, and cinematic scroll-driven animations.

---

## ✨ Features

- **🌐 3D Armillary Sphere (WebGL):** Real-time 3D gyroscope rendered with React Three Fiber (`@react-three/fiber` & `three`), featuring multi-axis orbital rings, particle dust, wireframe core, and interactive scroll deconstruction.
- **⚡ Cinematic Scroll Animations:** Powered by **GSAP** & **ScrollTrigger** for staggered text reveals, numeric counters, and magnetic hover micro-interactions.
- **🧈 Lenis Smooth Scrolling:** Buttery-smooth momentum scrolling synchronized with WebGL camera transformations.
- **💎 Glassmorphism Design System:** Tailored dark `#050505` aesthetic with antique gold `#C9A84C` accents and responsive layouts.
- **📄 Direct Resume Download:** 1-click local PDF download directly from the client.

---

## 🛠️ Tech Stack

- **Core:** React 19, TypeScript, Vite
- **3D & Graphics:** Three.js, React Three Fiber (R3F), @react-three/drei
- **Motion & Animations:** GSAP, ScrollTrigger, @gsap/react
- **Smooth Scroll:** Lenis
- **Icons & Styling:** Lucide React, Modern Vanilla CSS Design Tokens

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation & Run

```bash
# 1. Clone the repository
git clone https://github.com/HarshNsingh001/Portfolio-.git

# 2. Navigate into the project directory
cd Portfolio-

# 3. Install dependencies
npm install

# 4. Start the local dev server
npm run dev
```

The app will be available at `http://localhost:3000`.

### Production Build

```bash
npm run build
```
